# SMS Bot — Android

برنامه آزمایشی اندروید برای ترکیب مخاطبان ذخیره‌شده و شماره‌های تاریخچه SMS، حذف تکراری‌ها و ارسال انتخابی پیامک با تأیید کاربر. اطلاعات از دستگاه خارج نمی‌شود.

⚠️ **نصب APK تضمین دسترسی READ_SMS و SEND_SMS نیست.** محدودیت‌های Android و Play اعمال می‌شود. ارسال فقط برای مخاطبانی با رضایت قبلی و با تأیید دستی کاربر است.

ساخت: تب **Actions** → **Build SMS Bot APK** → اجرای workflow، سپس دانلود artifact.

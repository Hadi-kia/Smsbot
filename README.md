# SMS Bot (Android)

نسخه آزمایشی اندروید برای **ترکیب دفترچه تلفن و آدرس‌های تاریخچه SMS** (در صورت اعطای مجوز)، حذف شماره‌های تکراری، ورود CSV، انتخاب گیرندگان و ارسال پیامک گروهی با تأیید دستی.

- فقط روی گوشی اجرا می‌شود؛ مجوز اینترنت درخواست نمی‌شود.
- **هیچ پیامکی بدون انتخاب گیرنده، تیک رضایت و تأیید نهایی ارسال نمی‌شود.**
- محدودیت آزمایشی: ۱۰۰ مخاطب در هر مرحله، ۶ ثانیه فاصله بین شروع پیامک‌ها.
- ارسال با سیم‌کارت هزینه دارد؛ گزارش «شروع ارسال» به معنی تحویل قطعی پیامک نیست.
- کار در پس‌زمینه متوقف می‌شود. برای پیامک تبلیغاتی بدون رضایت مخاطب استفاده نکنید.
- READ_SMS / SEND_SMS از مجوزهای محدودشده اندروید هستند؛ نصب APK تضمین اعطای مجوز نیست. ممکن است لازم باشد نقش برنامه پیام‌رسان پیش‌فرض را دریافت کنید. این نمونه **برنامه SMS پیش‌فرض کامل نیست**.
- فرمت ورودی CSV: `name,number` یا فقط `number`؛ فایل نمونه در `docs/sample_numbers.csv`.

## ساخت APK بدون Android Studio
1. در مخزن GitHub تب **Actions** و سپس **Build SMS Bot APK** را باز کنید.
2. روی **Run workflow** بزنید (یا commit روی main بسازید).
3. پس از موفقیت، در قسمت **Artifacts** فایل `SMSBot-debug-APK` را دانلود کنید و `app-debug.apk` را از ZIP خارج کنید.
4. روی گوشی ابتدا با شماره شخصی خودتان آزمایش کنید. **وضعیت ساخت و تست واقعی گوشی تا پیش از اجرای workflow و نصب APK، تأیید نشده است.**

برای مخزن Public فقط کد عمومی منتشر شده است؛ هیچ شماره، کلید یا داده خصوصی را commit نکنید.

## نسخه چندپیام‌رسانه 0.2 (آزمایشی)

- دکمه‌های مستقل **تلگرام / واتساپ / روبیکا / بله** در صفحه جدید
- انتخاب یک عکس یا ویدیو از فایل‌های خود گوشی، و نوشتن متن همراه (بسته به پشتیبانی مقصد)
- اشتراک مستقیم از طریق Android ACTION_SEND به اپ رسمی نصب‌شده، بدون رمز یا دسترسی به حساب‌ها
- انتخاب محلی گروه‌بندی مخاطبان رضایتمند با تنظیم تعداد هر دسته و نمایش دسته‌ها
- کپی اختیاری شماره‌های یک دسته برای ساماندهی دستی؛ **شماره‌های این دسته به‌طور خودکار در پیام‌رسان مقصد انتخاب نمی‌شوند**
- اشتراک محتوا در هر بار از طریق برنامه مقصد و **تأیید کاربر در همان برنامه** انجام می‌شود؛ ارسال خودکار انبوه وجود ندارد
- آیکون آبی SMS؛ بدون افزودن مجوز اینترنت یا آپلود اطلاعات مخاطبان

### اعداد مستند، و تفاوت «سقف گروه» با «محدودیت نرخ ارسال»
| برنامه | داده مستند | کاربرد در این نسخه |
|---|---|---|
| WhatsApp | حداکثر ۲۵۶ عضو در هر Broadcast list؛ فقط گیرندگانی که شماره فرستنده را ذخیره کرده‌اند پیام Broadcast می‌گیرند. برخی مناطق محدودیت ماهانه جدید دارند. | فقط اطلاع‌رسانی؛ ایجاد Broadcast list خودکار نیست. |
| Telegram | گروه تا ۲۰۰ هزار عضو، کانال مشترکان نامحدود؛ Bot API تا حدود ۲۰ پیام/دقیقه در یک گروه و ۳۰ پیام/ثانیه در مجموع دارد | اعداد Bot API، سقف اشتراک دستی نیستند. |
| Rubika | سقف معتبر عمومی برای حساب شخصی تأیید نشد. | بخش‌بندی اختیاری صرفاً برای سازماندهی. |
| Bale | سقف معتبر عمومی برای حساب شخصی تأیید نشد. | بخش‌بندی اختیاری صرفاً برای سازماندهی. |

**توضیح فنی:** تا وقتی مجوز/حساب API رسمی و شناسه مخاطبان در پیام‌رسان مقصد وجود نداشته باشد، نمی‌توان تنها با داشتن شماره‌های SMS به‌صورت خودکار در هر پیام‌رسان به آن‌ها پیام فرستاد. این نسخه هیچ محدودیت ضداسپم یا نرخ ارسال را دور نمی‌زند.

برای امنیت، بازبینی گیرندگان و ارسال رسانه فقط با دسترسی و اقدام صریح صاحب گوشی انجام می‌شود.

## نسخه 0.3.0-alpha: پیشرفت دستی دسته‌ها و تست‌ها
- برای **هر کدام از چهار پیام‌رسان**، اندازه دسته، شماره دسته جاری و دسته‌های بررسی‌شده در همان نشست جداگانه نگه داشته می‌شوند.
- «این دسته را خودم بررسی کردم» فقط یک علامت محلی برای جلوگیری از اشتباه در کار دستی است؛ **هیچ تأیید تحویل یا ارسال خودکاری وجود ندارد**.
- تغییر اندازه گروه یا تعداد گیرندگان، علامت‌های پیشین همان پیام‌رسان را پاک می‌کند تا وضعیت اشتباه باقی نماند.
- باز و بسته شدن صفحه پیشرفت را پاک می‌کند؛ هنوز ذخیره‌سازی دائمی پیاده‌سازی نشده است.
- تست‌های واحد خودکار برای گروه‌بندی بدون گم‌شدن یا تکرار شماره و ادغام مخاطب/SMS/CSV اضافه شده‌اند.
- رفع مشکل نمایش خطوط شماره‌ها در پیش‌نمایش و تشخیص نوع فایل تصویر/ویدیو.
- فایل APK روی سرور GitHub کامپایل می‌شود، ولی **رفتار مجوزهای اندروید و پیام‌رسان‌ها باید روی گوشی واقعی تست شود**.
